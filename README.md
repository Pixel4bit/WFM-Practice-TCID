# 🇮🇩 Bahasa Indonesia

## 📌 Tentang Project

**WFM Billing Practice v1** merupakan aplikasi web sederhana yang dibuat sebagai bagian dari **Technical Test – Management Information System (MIS) Workforce Management**.

Aplikasi ini mensimulasikan proses pembuatan billing berdasarkan metode perhitungan **PPM** (Price Per Man Power) yang umum digunakan pada operasional Workforce Management.
Project dibuat menggunakan HTML, TailwindCSS, dan Vanilla JavaScript tanpa backend sehingga seluruh proses berjalan di browser.

---

## ✨ Fitur

- Dashboard Billing
- Kalkulasi Billing
- CRUD Data Karyawan
- Workflow Approval

---

# 🇺🇸 English

## 📌 About

**WFM Billing Practice v1** is a web application developed as part of a **Management Information System (MIS) Workforce Management Technical Test**.

The application simulates billing creation using Price Per Man Power (PPM) a common billing method
The project is built entirely on the frontend using HTML, TailwindCSS, and Vanilla JavaScript.
