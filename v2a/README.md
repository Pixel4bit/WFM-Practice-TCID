# 🇮🇩 Bahasa Indonesia

## 📌 Tentang Project

**WFM Billing Practice v2A** merupakan pengembangan dari versi pertama dengan peningkatan pada antarmuka, pengalaman pengguna, struktur kode, serta penambahan fitur simulasi workflow billing.

Versi ini dibuat sebagai penyempurnaan hasil Technical Test untuk posisi **MIS – Workforce Management**.
